# YSTEK — Refinamento de Gestão e Premium

Esta versão amplia o tratamento comercial dos planos e refina a interface do CRM/ERP sem remover as funcionalidades existentes.

## Premium SaaS
- Painel executivo com indicadores reais dos últimos 30 dias.
- Serviços com maior faturamento.
- Desempenho por lavador e comissão.
- Recebimentos por método de pagamento.
- Relatórios com período personalizado.
- Análise financeira avançada.
- Auditoria administrativa.
- Limites de dados maiores.

## Compatibilidade
O painel executivo é tolerante a falhas: se uma instalação legada ainda não possuir alguma estrutura de relatório, a operação principal do Dashboard continua carregando e a falha é registrada no log.

## Visual
A folha de estilo recebeu uma camada de refinamento para aparência de ERP/CRM: navegação mais estruturada, topbar fixa, hierarquia de títulos, tabelas, formulários, indicadores e cards comerciais mais consistentes, mantendo a identidade azul-marinho/azul da YSTEK.
